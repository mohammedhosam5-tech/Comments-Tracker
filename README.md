# Comments Tracker

A browser-based application for organizing project comments, tracking follow-up actions, and reporting progress.

## Features

- Create, edit, and organize comment records.
- Search and filter records.
- Monitor progress through dashboards.
- Import and export Excel files.
- Generate PDF reports.
- Create and compare snapshots.
- Export and restore application backups.

## Getting Started

1. Download this repository using Code → Download ZIP.
2. Extract the ZIP file.
3. Open index.html in your browser.
4. Start adding records or restore an existing backup.

No installation or application server is required.

## Data Storage and Backup

Records are saved in your browser's local storage.

- Data is specific to the browser and browser profile you use.
- Clearing browser data can remove saved records.
- Records do not automatically synchronize between devices.
- Use Export Backup regularly and before changing your browser or device.
- Use the restore function to recover data from a backup.

Uploading this application to GitHub stores its source code.
It does not upload or synchronize records saved in your browser.

## Technology

- HTML
- CSS
- JavaScript
- Browser local storage

## Updating the Application

Replace index.html with the updated version and commit the change
with a descriptive message. GitHub preserves the previous versions.

Export a backup before replacing the application file.
